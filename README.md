# coffeeShop

# Best Coffee Store in India

This project is a simple web application showcasing a coffee shop's offerings. It features a responsive layout where users can view different types of coffee products and place orders through an integrated form. 

## Live Demo
```bash
https://ojasvicoffeeshop.netlify.app/
```

## Features

- **Responsive Design**: The website is mobile-friendly and adjusts to different screen sizes.
- **Product Display**: Visual cards for various coffee products with images and prices.
- **Order Form**: Integration of an order form for customer queries.

## Technologies Used

- **HTML**: Structure of the web page.
- **CSS**: Styling and layout design (the stylesheet is linked as `coffee-shop.css`).
- **JavaScript**: For integrating the order form using JotForm.

## Installation

To set up this project locally, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/coffee-shop.git
    
2. Navigate to the Project Directory:
   ```bash
   cd coffee-shop

3. Open the HTML file in a Browser:

    Open index.html in your web browser to view the coffee shop.

## Usage
Home Link: <a href="index.html">HOME</a> directs to the home page.
Product Link: <a href="product.html">PRODUCT</a> directs to the product listing.
Contact Link: <a href="contact.html">CONTACT</a> directs to the contact page.
Order Section: The order form allows customers to submit their orders or inquiries directly.
